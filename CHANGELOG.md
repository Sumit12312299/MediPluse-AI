# Changelog

All notable changes to MediPulse AI are documented in this file.

## [Unreleased]

### Added
- AI-powered clinical scribe for tele-consultation sessions
- WebRTC-based peer-to-peer video consultation room
- PDF prescription export with QR code verification
- Notification center with multi-channel alert support (Email, SMS, System)
- Payment gateway integration (UPI, Net Banking, Card)
- Admin dashboard with analytics and doctor management
- Patient dashboard with appointment history and prescription viewer
- Doctor dashboard with schedule management and AI prescription generation
- RAG-based medical Q&A chatbot
- Role-based access control (Admin, Doctor, Patient)

### Changed
- Improved API error handling with structured response parsing
- Enhanced phone number validation for Indian mobile numbers

### Fixed
- Edge case in date formatter when input is null or undefined
- Currency formatter rounding for fractional amounts
